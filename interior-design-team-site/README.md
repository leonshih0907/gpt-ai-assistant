# Interior Design Team One-Page Website

## File structure

```
interior-design-team-site/
├─ public/
│  └─ images/
│     ├─ team-bg.jpg
│     ├─ alexandra-reid.jpg
│     ├─ jessica-morgan.jpg
│     ├─ michael-turner.jpg
│     ├─ priya-khan.jpg
│     ├─ lauren-wilson.jpg
│     └─ daniel-brooks.jpg
├─ src/
│  ├─ App.jsx
│  ├─ index.css
│  └─ main.jsx
├─ index.html
├─ package.json
├─ postcss.config.js
├─ tailwind.config.js
└─ vite.config.js
```

## Install and run

```bash
npm install
npm run dev
```

## Replace images

1. Copy your final hero photo to:
   - `public/images/team-bg.jpg`
2. Copy six individual studio portraits (one for each team member) to:
   - `public/images/alexandra-reid.jpg`
   - `public/images/jessica-morgan.jpg`
   - `public/images/michael-turner.jpg`
   - `public/images/priya-khan.jpg`
   - `public/images/lauren-wilson.jpg`
   - `public/images/daniel-brooks.jpg`
3. Keep these exact filenames (or update the paths in `src/App.jsx`).

No backend is required.
